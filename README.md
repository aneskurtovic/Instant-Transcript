# Instant-Transcript

Throw a YouTube link → get a full transcript instantly, behind a **shareable link
that expires**.

The transcript is generated by downloading the audio and running
[**Whisper locally**](https://github.com/SYSTRAN/faster-whisper) — we **never** use
YouTube's caption track, third-party transcript APIs, or cloud ASR. The resulting
link is readable by people *and* by AI fetchers: `/t/{id}/raw` serves clean
`text/plain`, and `/t/{id}` is fully server-rendered so the transcript sits in the
HTML body (no JavaScript required to read it).

---

## Features

- 🎙️ **Local transcription** with `faster-whisper` (CPU or GPU).
- 🔗 **Shareable links** with a configurable **TTL** (1 / 7 / 30 days, or any custom).
- 🤖 **AI-friendly**: `/t/{id}/raw` returns bare text with a context header block.
- 🧹 **Auto-expiry**: a background loop purges expired rows; expired links return **410 Gone**.
- ⏱️ **Timestamped segments** stored and rendered on the transcript page.
- 🛡️ **Guardrails**: max video length, rate limiting, optional yt-dlp cookie fallback.
- 📦 **One-command setup**: Docker Compose or a single `run.sh` — no manual steps.

## 🚀 One-command setup

Pick whichever you have. Both start the app at **<http://localhost:8000>** with
sensible defaults — no config needed.

### Option A — Docker (recommended, nothing to install but Docker)

```bash
docker compose up
```

That's it. It builds the image (Python + ffmpeg + deps), starts the server, and
persists everything (DB, temp audio, the downloaded Whisper model) in `./data`.
To run it detached: `docker compose up -d`. To stop: `docker compose down`.

### Option B — Local (Python 3.10+)

```bash
./run.sh
```

The script creates a virtualenv, installs dependencies, seeds `.env`, checks for
ffmpeg, and launches the server. On Windows, run `run.bat` instead.

> Prefer `make`? `make docker` (Option A) · `make run` (Option B) · `make help`
> for everything else.

Then open <http://localhost:8000>, paste a YouTube URL, and hit **Transcribe**.

> **First run** downloads the Whisper model (cached afterwards, so subsequent runs
> start fast). The default `small` model runs comfortably on CPU; switch to
> `large-v3` on a GPU for best quality / longer videos (see Configuration).

### Prerequisites

- **Docker route:** just [Docker](https://docs.docker.com/get-docker/) (Compose v2 is built in).
- **Local route:** **Python 3.10+** and **ffmpeg**
  (`sudo apt-get install -y ffmpeg` · macOS: `brew install ffmpeg`).
  `run.sh` warns you if ffmpeg is missing.

**GPU:** base the image on an `nvidia/cuda` runtime image, run with
`--gpus all`, and set `DEVICE=cuda COMPUTE_TYPE=float16` (e.g. in `.env`).

## Languages

Transcription uses OpenAI's Whisper (via `faster-whisper`), which supports
**~99 languages** with **automatic language detection**. Leave the language field
empty (the default) and Whisper detects it from the audio; the detected code is
shown on the transcript page and in the `/raw` header.

To **force** a language — useful for short or noisy clips where auto-detect
guesses wrong — pass an ISO 639-1 code in the UI's "Force language" field or in
the API body (`"language": "bs"`).

Auto-detect works well for **ex-Yugoslav languages** — Bosnian (`bs`),
Croatian (`hr`), Serbian (`sr`). For the best quality on these, use the
`large-v3` model (GPU recommended).

## Configuration

All settings are environment variables (see [`.env.example`](.env.example)).

| Variable | Default | Purpose |
|---|---|---|
| `WHISPER_MODEL` | `small` | `tiny`/`base`/`small`/`medium`/`large-v3`. Bigger = better + slower. |
| `DEVICE` | `cpu` | `cpu` or `cuda`. |
| `COMPUTE_TYPE` | `int8` | `int8` (CPU) or `float16` (GPU). |
| `DEFAULT_TTL_HOURS` | `168` | Default link lifetime (7 days). |
| `MAX_TTL_HOURS` | `720` | Upper bound for a per-request TTL. |
| `MAX_DURATION_MIN` | `120` | Reject videos longer than this. |
| `BASE_URL` | `http://localhost:8000` | Public origin used to build share links. |
| `DB_PATH` | `data/transcripts.db` | SQLite file path. |
| `TMP_DIR` | `data/tmp` | Temp audio directory. |
| `CLEANUP_INTERVAL_MIN` | `15` | How often the cleanup loop runs. |
| `RATE_LIMIT_ENABLED` | `true` | Toggle slowapi rate limiting. |
| `RATE_LIMIT` | `10/hour` | Limit on `POST /api/transcribe` per client. |
| `YT_DLP_COOKIES` | — | Path to a Netscape cookies file (bot-check fallback). |
| `YT_DLP_COOKIES_FROM_BROWSER` | — | Browser to pull cookies from, e.g. `chrome`. |

## API

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/` | Submit UI. |
| `POST` | `/api/transcribe` | Body `{ url, ttl_hours?, language? }` → `{ id, share_url, raw_url, status }`. |
| `GET` | `/api/status/{id}` | `{ status, title, language, error?, share_url, raw_url }`. |
| `GET` | `/t/{id}` | Server-rendered HTML page (queued / processing / done / error / expired). |
| `GET` | `/t/{id}/raw` | `text/plain` transcript. **202** while processing, **410** when expired/missing. |

### The `/raw` contract (this is the point)

```bash
curl https://your-host/t/<id>/raw
```

```
Title: Some Talk
Source URL: https://www.youtube.com/watch?v=…
Language: en
Transcribed with: Whisper medium (local)
Generated: 2026-06-02 12:00 UTC
Expires: 2026-06-09 12:00 UTC
------------------------------------------------------------

<the transcript text…>
```

`Content-Type: text/plain; charset=utf-8`, no markup, no JS — paste it straight
into an AI.

IDs are `secrets.token_urlsafe(9)` (~12 chars, unguessable). There is **no public
index or enumeration** — links are unlisted by obscurity.

## Deployment — making links actually shareable

For links to reach other people and AI fetchers, the app needs a **public HTTPS
URL**. Two common options:

- **VPS + reverse proxy** — run behind **Caddy** or **nginx** with a domain and
  automatic HTTPS. Cleanest for a permanent service. Set `BASE_URL` to your domain.
- **Tunnel from a local box** — keep it local and expose it via
  **Cloudflare Tunnel** (`cloudflared tunnel --url http://localhost:8000`) or
  **ngrok** (`ngrok http 8000`). Set `BASE_URL` to the tunnel's HTTPS URL so the
  share/raw links point at the public host.

**Compute reality:** Whisper is the bottleneck. A GPU is strongly recommended for
`large-v3` or long videos; CPU-only is fine for short clips on `small`/`medium`.
Keep `MAX_DURATION_MIN` set to bound cost.

## Security & privacy notes

- **No auth by design** — *anyone with the link can read the transcript.* The UI
  says so. If you need private links later, add a bearer-token check on `/t/{id}`.
- Audio is downloaded to a temp file, transcribed, and **deleted immediately** —
  only the text is stored.
- yt-dlp occasionally hits YouTube bot checks; pin-but-update it and use the
  `YT_DLP_COOKIES*` fallback if needed.
